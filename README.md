## 📂 Featured Engineering Projects

### 🔄 [DevSecOps CI/CD & GitOps Infrastructure](https://github.com/abhisheksingh22se/devsecops-cicd-pipeline)
An end-to-end declarative pipeline to securely build, deploy, and monitor applications.
* **Stack:** GitHub Actions, ArgoCD, Kustomize, AWS EKS, Prometheus/Grafana.
* **Impact:** Enforces strict shift-left security (Trivy/Snyk CVE blocking), passwordless AWS OIDC authentication, and automated GitOps deployment synchronization.

### 🛡️ [Smart Score CLI & GitHub Action](https://github.com/abhisheksingh22se/smart-score-cli)
A containerized Web3 DevSecOps tool that scores smart contracts on security and efficiency metrics. 
* **Stack:** Python, Docker, GitHub Actions, Pydantic, Hardhat.
* **Impact:** Translates rigorous academic research into an automated CI/CD quality gate to block critical vulnerabilities before deployment. 

### 🤖 [Event-Driven AIOps Remediation Engine](https://github.com/abhisheksingh22se/automation-lambda-aiops-remediator)
An automated framework that acts as a serverless Kubernetes operator for incident response.
* **Stack:** AWS Lambda, EventBridge, CloudWatch Anomaly Detection, Python Boto3.
* **Impact:** Reduced infrastructure MTTR by automatically resolving high CPU/Memory events and clearing false-positive alerts.

### 🏗️ [Infrastructure EKS Provisioner](https://github.com/abhisheksingh22se/infrastructure-eks-terraform-provisioner)
Modular Infrastructure-as-Code (IaC) to provision a production-grade AWS environment.
* **Stack:** Terraform, AWS EKS, VPC, IAM Roles for Service Accounts (IRSA).
* **Impact:** Deploys a zero-trust, multi-environment architecture enforcing least-privilege network isolation.

### ⚡ [High-Throughput FastAPI Microservice](https://github.com/abhisheksingh22se/backend-fastapi-mongo-service)
A production-grade, asynchronous REST API designed for high-concurrency data ingestion.
* **Stack:** Python, FastAPI, MongoDB, Docker.
* **Impact:** Demonstrates domain-agnostic backend containerization optimized for non-blocking I/O and rapid deployment.
