## 🧠 Engineering Philosophy: The "SRE" Approach
I build resilient systems by applying distinct disciplines to every layer of the cloud stack:

* **Reliability & Observability (The Brain):** Moving beyond static thresholds. I apply Anomaly Detection and SLO-driven telemetry to understand system drift and cut false-positive alerts.
* **Event-Driven Remediation (The Hands):** Engineering serverless workflows (Lambda/EventBridge) that automatically resolve Kubernetes incidents, drastically reducing Mean Time to Recovery (MTTR).
* **Security as Code (The Shield):** Leveraging my MS in Cybersecurity to embed "Shift-Left" guardrails, Zero-Trust network isolation, and IRSA identity management directly into the CI/CD pipeline.
